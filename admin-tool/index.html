How to Use This Tool

  1. Click "Upload Photo" to select an image from your computer
  2. Fill in the photo details (title, category, location, etc.)
  3. Click "Save Photo" to upload the data
  4. The photo will be added to your site's data
  5. The photo will appear on your site after the next GitHub build

Important Note:

This admin tool uses Cloudinary for image storage and GitHub's API to update your site data. Your Cloudinary credentials are stored in your browser's local storage for convenience.
